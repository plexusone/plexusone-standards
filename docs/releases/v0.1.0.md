# v0.1.0 — 2026-05-31

*Backfilled 2026-08-29 from CHANGELOG.json — no release-notes doc existed
at the time this version shipped.*

The initial release, as `plexusone-design-system` (renamed to
`plexusone-standards` in v0.2.0): design tokens and brand configuration
for PlexusOne properties, with a single `design-system.json` source of
truth validated against [design-system-spec](https://github.com/plexusone/design-system-spec)'s
JSON Schema.

## Highlights

Initial PlexusOne design system with comprehensive design tokens and
output profiles.

## Added

- Design system JSON specification with a `$schema` reference.
- Foundation tokens: colors (dark theme palette), typography
  (Inter/JetBrains Mono), spacing scale, border radius.
- Component tokens: buttons (primary, secondary, ghost variants), inputs,
  cards with semantic styling.
- Semantic tokens: status colors (success, warning, error, info) and
  state colors (hover, focus, disabled).
- Accent color palette: violet, cyan, pink, amber, emerald for branding
  flexibility.
- Output profiles: website (LCD-optimized), marp (projection-optimized),
  pdf (print-optimized).
- CSS variable generation config with customizable prefix, selector, and
  token mappings.
