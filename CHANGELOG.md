## [v0.2.0] - 2026-08-29 ([`d38057e`](https://github.com/plexusone/plexusone-standards/commit/d38057e))

### Highlights

- Restructured into a multi-domain standards repo (design-system, api/rest, resourceref, naming) and added the plexusone-rest REST API style profile and the prn resource-reference scheme instance

### Added

- api/rest/plexusone-rest.api-style.json: 17-rule REST API style profile covering naming, errors, pagination, SystemForge auth/scopes, PRN references, run resources, streaming, and versioning, with 3 conformance levels ([`e2e138c`](https://github.com/plexusone/plexusone-standards/commit/e2e138c))
- Generated api/rest/plexusone-rest.{spectral.yaml,rubric.json,guide.md} artifacts from the API style profile ([`5948afe`](https://github.com/plexusone/plexusone-standards/commit/5948afe))
- resourceref/prn-profile.json: the real prn resource-reference scheme instance (authorities, tenant-scoped and ecosystem-artifact shapes, resourceType registries for dashforge and actionforge, version/alias grammar), validated by a Go test module against resourceref's scheme engine ([`09823a5`](https://github.com/plexusone/plexusone-standards/commit/09823a5))
- naming/README.md: module and product naming-conventions standard (omni*, *forge, *-core, plain functional names) with PRN/scope grammar cross-references ([`d38057e`](https://github.com/plexusone/plexusone-standards/commit/d38057e))

### Changed

- Restructured repo into domain directories: design-system.json, package.json, agents/, examples/, loops/, and llm-context.md moved into design-system/; root README became a cross-domain index ([`0b4f833`](https://github.com/plexusone/plexusone-standards/commit/0b4f833))

### Fixed

- api/rest PX-003 URL-pattern rule: removed an overly permissive bare /v{N}/... alternative that silently accepted any unversioned path, caught by linting an api-style-spec exemplar before and after the fix ([`5948afe`](https://github.com/plexusone/plexusone-standards/commit/5948afe))

### Internal

- Updated CHANGELOG.json/CHANGELOG.md self-references from plexusone-design-system to plexusone-standards; documented the per-domain commit-scope convention ([`1b7bce1`](https://github.com/plexusone/plexusone-standards/commit/1b7bce1))
