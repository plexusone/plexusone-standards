## [v0.2.0] - 2026-11-08 ([`cdb1e44`](https://github.com/plexusone/plexusone-standards/commit/cdb1e44))

### Highlights

- Restructured into a multi-domain standards repo (design-system, api/rest, resourceref, naming) and added the plexusone-rest REST API style profile and the prn resource-reference scheme instance
- plexusone-rest v1.1.0: 22 rules, adding capability-scoped /api/{api}/v{N}/ paths beside /api/v{N}/, organization selectors authorized against the principal, operation audiences, preconditions, dry runs, content-addressed uploads and read-only public endpoints

### Added

- api/rest/plexusone-rest.api-style.json: 17-rule REST API style profile covering naming, errors, pagination, SystemForge auth/scopes, PRN references, run resources, streaming, and versioning, with 3 conformance levels ([`be02769`](https://github.com/plexusone/plexusone-standards/commit/be02769))
- Generated api/rest/plexusone-rest.{spectral.yaml,rubric.json,guide.md} artifacts from the API style profile ([`1e1ca35`](https://github.com/plexusone/plexusone-standards/commit/1e1ca35))
- resourceref/prn-profile.json: the real prn resource-reference scheme instance (authorities, tenant-scoped and ecosystem-artifact shapes, resourceType registries for dashforge and actionforge, version/alias grammar), validated by a Go test module against resourceref's scheme engine ([`34e3e14`](https://github.com/plexusone/plexusone-standards/commit/34e3e14))
- naming/README.md: module and product naming-conventions standard (omni*, *forge, *-core, plain functional names) with PRN/scope grammar cross-references ([`0a776a1`](https://github.com/plexusone/plexusone-standards/commit/0a776a1))
- api/rest PX-018 to PX-022: every operation declares x-audience (public, first-party or internal); whole-resource replacements take a precondition; bulk and apply operations offer a dry run with opt-in pruning; file sets upload by content address; unauthenticated endpoints are read-only under /public/ ([`8a0574d`](https://github.com/plexusone/plexusone-standards/commit/8a0574d))

### Changed

- Restructured repo into domain directories: design-system.json, package.json, agents/, examples/, loops/, and llm-context.md moved into design-system/; root README became a cross-domain index ([`4047bf4`](https://github.com/plexusone/plexusone-standards/commit/4047bf4))
- api/rest PX-003 allows /api/{api}/v{N}/ beside the /api/v{N}/ default and camelCase path parameters; PX-009 allows a stable slug beside the ID; PX-016 lets the path select an organization, authorized against the principal on every request. Profile version 1.1.0 ([`5259c4a`](https://github.com/plexusone/plexusone-standards/commit/5259c4a))

### Fixed

- api/rest PX-003 URL-pattern rule: removed an overly permissive bare /v{N}/... alternative that silently accepted any unversioned path, caught by linting an api-style-spec exemplar before and after the fix ([`1e1ca35`](https://github.com/plexusone/plexusone-standards/commit/1e1ca35))

### Documentation

- api/rest README: versioned path forms and API audiences, with an .api-style.yaml example ([`88ce21b`](https://github.com/plexusone/plexusone-standards/commit/88ce21b))

### Build

- resourceref requires a published github.com/plexusone/resourceref version instead of a replace to a sibling checkout, so the module builds from a clean clone ([`cdb1e44`](https://github.com/plexusone/plexusone-standards/commit/cdb1e44))

### Internal

- Updated CHANGELOG.json/CHANGELOG.md self-references from plexusone-design-system to plexusone-standards; documented the per-domain commit-scope convention ([`d237ef9`](https://github.com/plexusone/plexusone-standards/commit/d237ef9))
